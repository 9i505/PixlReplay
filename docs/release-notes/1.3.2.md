Pixl Replay 1.3.2: clearer clips at your screen's full frame rate.

- Custom quality: the slider now goes right for a sharper picture. Before, right meant less sharp, so pushing it all the way made clips blurry; if you set Custom, check it once.
- A short stall (recording stopping for a minute with no game behind it) no longer drops recording to 60 fps: it starts again as you set it.
- When a game really does take the graphics card, recording goes lighter for a day instead of a week, then back to your frame rate.

صار شريط الجودة المخصصة: كل ما سحبته أكثر صارت الصورة أوضح (قبل كان العكس). وتوقف التسجيل لدقيقة ما عاد ينزله إلى 60 إطارًا، والتخفيف بسبب لعبة صار ليوم واحد بدل أسبوع.
