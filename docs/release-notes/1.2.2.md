Pixl Replay 1.2.2: keys that keep working.

- Keys in every game: many games tell Windows to hold back other apps' shortcuts while they are in front, so a save key could do nothing after a while in a game. Pixl Replay now also watches the keys itself (as OBS does) and runs each press once, whichever way it arrives.
- Keys never stay off: while a key is typed into a hotkey box they are let go, and they now always come back on their own (20 seconds at most).
- Pixl Replay writes down in its log if it ever stops answering for a moment, so any such problem can be found.

الاختصارات تشتغل دائمًا حتى داخل الألعاب التي تمنع اختصارات البرامج الأخرى، وما تتعطل بعد وقت طويل.
