Pixl Replay 1.2.0: smoother clips, faster saves, a new icon.

- Smooth clips: Pixl Replay never records faster than the screen it captures. A 165 Hz screen records at 165 fps even when 240 is chosen: no repeated frames, smaller files that play without stutter. The Quality page shows each screen's maximum.
- Faster saves: smaller buffers mean a clip is written in a moment.
- New icon: a coral tile, easy to tell apart from Pixl on the taskbar. The tray tile changes color with the state, with a red dot while recording.
- Sharing: a clip that has to fit a size limit now always fits, even on graphics cards that overshoot small sizes.
- Fixed a rare error when a recording ended while an update was starting.
