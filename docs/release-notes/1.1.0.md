Pixl Replay 1.1.0: record more than one screen.

- More screens: on the Capture page, turn on any other screen (up to three) and it is recorded beside the main one.
- Every save makes a clip of each screen, with the same time and the screen in its name ("... - Screen 2.mp4"). Quick saves and full recordings too.
- One sound for all of them, one save sound and one notice per save, and the tray's undo takes all of that save's files.

تسجيل أكثر من شاشة: من صفحة الالتقاط شغّل أي شاشة ثانية (حتى ثلاث)، وكل حفظ يطلع مقطع لكل شاشة.
