Kairos 1.1.1 test build: for testing only.

- Mixer channels as sources: add a playback device (GoXLR Music, RØDECaster Chat and others) in Add source, each on its own track.
- RØDECaster and Elgato Wave Link are known like SteelSeries Sonar and GoXLR; GoXLR's VOD is never offered as a source.
- Encoder speed goes up to p5: NVIDIA's p6 and p7 turned on look-ahead, which made clips freeze while a game used the whole graphics card.
- Full screen, Games and One app: while a game shows its own picture, the capture under it (the screen, or the app's window) no longer runs too. It took every picture twice from a graphics card the game already filled, and clips froze with sound in heavy games.
- Recording goes ahead of the game on the processor from the first second: a game that kept every core busy (8 threads in ARC Raiders) left Kairos's picture threads waiting while the sound went on, and clips froze with sound. The picture threads now run at the top priority Windows gives without administrator rights, and Kairos above normal; Smart Save stays at the game's level. Kairos does the same work as before (a few milliseconds a frame), so the game loses nothing more; in a test with every core taken, frames lost went from about 30% to none.
- Recording that falls behind a game that fills the graphics card (for a whole minute, on that PC only) now goes lighter step by step: first NVIDIA's encoder without its extra passes on the card (same quality, clips about 5% larger), then Kairos asks Windows to serve its recording on the card before the game (the top GPU priority, as Sunshine and NVIDIA's own recorder use; nothing else changes), then 60 fps and 1080p at most, then 30 fps, then the CPU where it has room. Before, an 8-thread CPU at 1080p60 had no step left and the picture froze.
- A game Kairos cannot open (run as administrator, or guarded by its anti-cheat) is recorded from the screen, which a game in exclusive full screen can leave black. Once such a game is left, a calm tip says, once per game, to set its display mode to Borderless. Players already on Borderless never see it.
- The log says how much of the graphics card's memory Kairos uses and how much Windows allows it.
- A clip from the replay on the disk ends with its last picture.
- Keys F13-F24 (what mouse software sends for a side button) also work while Shift or Ctrl is held.
- Games that run as administrator (Genshin Impact, Star Rail, Wuthering Waves and others) are recorded from the screen straight away, without trying to hook them every 2 seconds, and their clips go in their own folder instead of "Desktop".
- The log says where each save came from.
- Smart Save: a phrase whose three tries differ a lot is asked again (up to twice), then kept with a warning that it may save while you talk.
